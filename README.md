# 간편정리

## 주요 진행 단계

1. 기본계획 및 특별정비구역 지정: 지자체의 노후계획도시 기본계획에 따라 통합재건축 등 구역 지정을 고시합니다.
2. 사업시행자 지정 및 설계·시공사 선정: 특별정비구역 내 주민 동의를 거쳐 조합이나 신탁사를 사업시행자로 지정하고, 설계자 및 시공사를 선정합니다.
3. 사업시행인가: 건축 계획과 사업 계획을 지자체로부터 공식 승인받습니다.
4. 관리처분인가: 조합원 분양 신청, 자산 평가 후 최종 분담금과 사업 계획을 확정합니다.
5. 이주·철거 및 준공: 기존 주거지 철거 후 공사를 진행합니다.

## 주요 제한 사항

- 투기과열지구 지정에 따른 제한
  - 조합설립 인가 또는 사업시행자 지정 고시에 의한 조합원 지위양도 원칙적 금지.
